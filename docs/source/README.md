# Assignment source material

This directory preserves the normalized Homework 4 inputs used to define and
verify the implemented system.

- [`01_homework_4_assignment.md`](01_homework_4_assignment.md) is a faithful
  transcription of the written assignment.
- [`02_original_big_picture_mermaid.md`](02_original_big_picture_mermaid.md) is
  a semantic Mermaid transcription of the original architecture diagram.

These files are reference requirements from the earlier Homework 4 system, not
descriptions of the Rust runtime and not an implementation claim.

For the adopted Rust-core/Python-orchestration MVP, start with
[`../architecture/README.md`](../architecture/README.md). The Rust repository
does not yet have a requirement-to-code traceability map; the implementation
brief defines the acceptance criteria that the first implementation must make
traceable to tests.
